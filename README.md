# AnniseHerbal

A collaborative e-commerce website project for Annise Herbal, a family business focused on essential oil products and natural wellness.

## Overview

This project was created to support Annise Herbal’s online presence, product presentation, and customer shopping experience. The website includes a responsive front-end interface, product-focused layout, and e-commerce functionality developed in collaboration with a small team.

## Tech Stack

- React
- TypeScript
- CSS
- Node.js
- Git & GitHub

## Features

- Responsive front-end interface
- Product-focused pages
- Essential oil product presentation
- Brand and visual content support
- User-friendly layout for browsing products
- Collaborative front-end and backend development structure
