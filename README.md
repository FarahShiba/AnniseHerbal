# AnniseHerbal

A collaborative e-commerce website project for Annise Herbal, a family business focused on essential oil products and natural wellness.

## Overview

This project was created to support Annise Herbal’s online presence, product presentation, and customer shopping experience. The website includes a responsive front-end interface, product-focused layout, e-commerce functionality, and backend/API integration developed in collaboration with a small team.

## Tech Stack

- React
- TypeScript
- CSS
- Node.js
- REST API integration
- Git & GitHub

## Features

- Responsive front-end interface
- Product-focused pages
- Essential oil product presentation
- Brand and visual content support
- User-friendly layout for browsing products
- Front-end integration with backend/API functionality
- Collaborative front-end and backend development structure
